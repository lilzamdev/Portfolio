WHO AM I?

A student and developer who learns best by building things.

NARRATIVE // HOW I GOT STARTED

"I didn't start with a big master plan. I just asked: How does this actually work?"

Every project I've started began with curiosity about a mechanic or an idea. I open the editor, build a first version, break it, and figure out why. That loop taught me most of what I know — and it's how I pick up new tools quickly.

"Let's see what happens if I try."

— Personal motto
01

Understand the basics

Frameworks change. Logic, rendering, and how data moves stay with you.

02

Learn from broken code

Errors show me where my assumptions were wrong, so I can fix them.

03

Care about the details

Clean layouts and smooth interactions make software feel great to use.
